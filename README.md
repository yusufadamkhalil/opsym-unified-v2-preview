# Op-Sym Mobile 5.1 - Complete Visual Prototype

This is intentionally a **visual prototype only**.

It contains:
- no Google Apps Script backend;
- no Google Sheets connection;
- no old Op-Sym renderers;
- no old mobile CSS;
- no desktop code.

Its purpose is to approve the complete mobile experience before backend integration.

## Screens
1. Home
2. Today
3. Tasks
4. Inbox
5. Week
6. Month
7. Year
8. Commitments
9. Analytics
10. More
11. Settings
12. Capture
13. Task Detail

All screens support both portrait and landscape. Landscape is a separate composition, not a stretched portrait layout.

## Run
Open `index.html` in a browser, or upload the whole folder to a GitHub Pages test repository.

## Important
Do **not** copy these files into Apps Script yet.
Approve the visual design first.
